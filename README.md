# EduGenie Live Project\n\nA runnable FastAPI + HTML/CSS/JavaScript learning assistant using Google Gemini. Features: Q&A, concept simplification, quiz generation, note summarization, and study recommendations.\n\n## Run on Windows\n1. Install Python 3.10 or newer.\n2. Extract this ZIP and open PowerShell in the project folder.\n3. Run:\n```powershell\npy -m venv .venv\n.venv\\Scripts\\Activate.ps1\npip install -r requirements.txt\ncopy .env.example .env\nnotepad .env\n```\n4. Put your Gemini API key after `GEMINI_API_KEY=` in `.env`. Keep this file private.\n5. Start: `uvicorn app:app --reload`\n6. Open http://127.0.0.1:8000\n\nRequires internet and a valid Gemini API key. AI output may be inaccurate; verify important material. This is a local runnable version, not yet hosted publicly.\n
